# MufarTech Forms

A full-featured form builder platform built with Next.js 16, React 19, and Tailwind CSS 4.

## Features

- User authentication (signup, login, forgot password, email verification)
- Dashboard with form builder, analytics, responses, templates, and integrations
- Billing, team, and settings management
- Dark/light theme support
- Built with shadcn/ui components

## Prerequisites

- [Node.js](https://nodejs.org/) v20.9.0 or later
- npm (comes with Node.js) or [pnpm](https://pnpm.io/)

## Cloning the Project

```bash
git clone https://github.com/mufar-tech/forms.git
cd forms
```

## Installation

Using npm (recommended):

```bash
npm install
```

Or using pnpm, if you prefer:

```bash
pnpm install
```

## Running the Project

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Command          | Description                          |
| ---------------- | ------------------------------------ |
| `npm run dev`    | Starts the development server        |
| `npm run build`  | Creates a production build           |
| `npm run start`  | Starts the production server         |
| `npm run lint`   | Runs ESLint to check for code issues |

## Production Build

To build and run in production mode:

```bash
npm run build
npm run start
```
